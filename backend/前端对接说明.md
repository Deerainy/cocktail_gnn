# 前端对接说明 - 中英文字段

## 概述

后端API已支持中英文字段返回，具体字段如下：

## 1. 配方信息接口

### 接口地址
- `GET /api/recipes` - 获取所有配方
- `GET /api/recipes/{recipe_id}` - 获取单个配方详情

### 中英文字段

| 字段名 | 说明 | 示例 |
|--------|------|------|
| `name` | 配方英文名 | "Flor de Amaras" |
| `recipe_name_zh` | 配方中文名 | "阿马罗之花" |

### 返回示例
```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "recipe_id": "1",
    "name": "Flor de Amaras",
    "recipe_name_zh": "阿马罗之花",
    "instructions": "...",
    "glass": "coupe",
    "tags": "tequila, mezcal, cocktail",
    "image_url": "https://example.com/image.jpg",
    "is_alcoholic": true
  }
}
```

## 2. 原料信息接口

### 接口地址
- `GET /api/recipes/{recipe_id}/ingredients` - 获取配方原料列表

### 中英文字段

| 字段名 | 说明 | 示例 |
|--------|------|------|
| `name_norm` | 原料原始名称 | "mezcal" |
| `canonical_name` | 原料标准英文名 | "mezcal" |
| `canonical_name_zh` | 原料标准中文名 | "梅斯卡尔酒" |
| `anchor_name` | 风味锚点名称 | "agave" |

### 返回示例
```json
{
  "code": 0,
  "message": "ok",
  "data": [
    {
      "ingredient_id": "1",
      "line_no": 1,
      "amount": 1.5,
      "unit": "oz",
      "role": "base_spirit",
      "raw_text": "1.5 oz Mezcal",
      "ingredient": {
        "ingredient_id": "1",
        "name_norm": "mezcal",
        "canonical_id": "1",
        "canonical_name": "mezcal",
        "canonical_name_zh": "梅斯卡尔酒",
        "category": "Spirit",
        "abv": 40.0,
        "anchor_name": "agave",
        "anchor_form": "spirit"
      }
    }
  ]
}
```

## 3. 前端使用建议

### 显示优先级
1. **配方名称**：优先显示 `recipe_name_zh`，为空时显示 `name`
2. **原料名称**：优先显示 `canonical_name_zh`，为空时显示 `canonical_name`

### 代码示例
```javascript
// 获取配方列表
fetch('http://127.0.0.1:8000/api/recipes')
  .then(response => response.json())
  .then(result => {
    if (result.code === 0) {
      const recipes = result.data.map(recipe => ({
        id: recipe.recipe_id,
        // 优先显示中文名，没有则显示英文名
        name: recipe.recipe_name_zh || recipe.name,
        originalName: recipe.name, // 保留英文名备用
        image: recipe.image_url,
        isAlcoholic: recipe.is_alcoholic
      }));
      // 渲染配方列表...
    }
  });

// 获取原料列表
fetch('http://127.0.0.1:8000/api/recipes/1/ingredients')
  .then(response => response.json())
  .then(result => {
    if (result.code === 0) {
      const ingredients = result.data.map(item => ({
        id: item.ingredient_id,
        amount: item.amount,
        unit: item.unit,
        role: item.role,
        // 优先显示中文名
        name: item.ingredient.canonical_name_zh || item.ingredient.canonical_name,
        englishName: item.ingredient.canonical_name
      }));
      // 渲染原料列表...
    }
  });
```

## 4. 注意事项

1. **字段可能为空**：`recipe_name_zh` 和 `canonical_name_zh` 可能为 `null`，请做好空值处理
2. **编码问题**：数据库已使用 `utf8mb4` 编码，支持完整的Unicode字符（包括emoji）
3. **API基础地址**：`http://127.0.0.1:8000/`

## 4. 实体识别与处理接口

### 4.1 实体处理接口

#### 接口地址
- `POST /api/entity/process` - 处理单个文本的实体识别
- `POST /api/entity/batch_process` - 批量处理文本的实体识别

#### 请求示例

**单个文本处理：**
```json
{
  "text": "I want a smoky Margarita with lime juice and mezcal."
}
```

**批量处理：**
```json
{
  "texts": [
    "I want a smoky Margarita with lime juice and mezcal.",
    "给我一杯龙舌兰酒加青柠。"
  ]
}
```

#### 返回示例

**单个文本处理：**
```json
{
  "text": "I want a smoky Margarita with lime juice and mezcal.",
  "entities": [
    {
      "text": "smoky",
      "label": "FLAVOR",
      "start": 9,
      "end": 14,
      "processing_level": "lexicon_rule",
      "confidence": 1.0,
      "normalized_flavor": "aroma"
    },
    {
      "text": "Margarita",
      "label": "RECIPE",
      "start": 15,
      "end": 24,
      "processing_level": "lexicon_rule",
      "confidence": 1.0,
      "entity_id": 723,
      "normalized_name": "Margarita"
    }
  ],
  "processing_level": "lexicon_rule"
}
```

### 4.2 审核管理接口

#### 接口地址
- `GET /api/entity/review_tasks` - 获取审核任务列表
- `GET /api/entity/review_tasks/{reviewId}` - 获取审核任务详情
- `POST /api/entity/review` - 提交审核结果

#### 审核任务列表返回示例

```json
{
  "total": 3,
  "tasks": [
    {
      "review_id": "61227665-d163-4db1-8f97-4e338283a354",
      "original_text": "lime 的邻域有什么食材",
      "status": "pending",
      "processing_level": "llm_analysis",
      "created_at": "2026-04-02T18:13:59+08:00",
      "entities": [
        {
          "entity_id": "021e62b1-d081-4619-8ecb-8b7f9af4d174",
          "text": "lime",
          "label": "FLAVOR",
          "start_pos": 0,
          "end_pos": 4,
          "processing_level": "unrecognized",
          "confidence": 0.0,
          "context": "lime 的邻域有什么食材"
        }
      ]
    }
  ]
}
```

#### 审核任务详情返回示例

```json
{
  "review_id": "61227665-d163-4db1-8f97-4e338283a354",
  "original_text": "lime 的邻域有什么食材",
  "status": "pending",
  "processing_level": "llm_analysis",
  "created_at": "2026-04-02T18:13:59+08:00",
  "entities": [
    {
      "entity_id": "021e62b1-d081-4619-8ecb-8b7f9af4d174",
      "text": "lime",
      "label": "FLAVOR",
      "start_pos": 0,
      "end_pos": 4,
      "processing_level": "unrecognized",
      "confidence": 0.0,
      "context": "lime 的邻域有什么食材"
    }
  ]
}
```

#### 审核提交请求示例

```json
{
  "review_id": "uuid-123",
  "entity_id": "entity-456",
  "original_text": "Margareta",
  "approved_candidate": {
    "text": "Margarita",
    "label": "RECIPE",
    "entity_id": 723,
    "normalized_name": "Margarita"
  },
  "add_as_alias": true
}
```

#### 审核提交返回示例

```json
{
  "status": "success",
  "message": "审核结果已处理",
  "data": {
    "review_id": "uuid-123",
    "entity_id": "entity-456",
    "action": "create_entity_and_add_alias",
    "alias": "Margareta",
    "canonical_id": "new-entity-id",
    "canonical_name": "Margarita"
  }
}
```

#### 审核提交的action类型

| action类型 | 说明 |
|-----------|------|
| `add_alias` | 为现有实体添加别名 |
| `create_entity` | 创建新实体 |
| `create_entity_and_add_alias` | 创建新实体并添加别名 |

#### 注意事项

1. 当审核提交时，如果 `approved_candidate` 中的 `entity_id` 不存在，系统会自动创建新的实体
2. 新实体的 `entity_id` 会自动生成 UUID 格式
3. 新实体的 `name` 和 `normalized_name` 会使用 `approved_candidate` 中的 `text` 和 `normalized_name`
4. 新实体的 `label` 会使用 `approved_candidate` 中的 `label`，如果没有则默认为 `UNKNOWN`

#### 实体处理
```javascript
// 处理单个文本
async function processText(text) {
  try {
    const response = await fetch('http://127.0.0.1:8000/api/entity/process', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({ text })
    });
    
    const result = await response.json();
    return result;
  } catch (error) {
    console.error('处理文本失败:', error);
    throw error;
  }
}

// 批量处理文本
async function batchProcess(texts) {
  try {
    const response = await fetch('http://127.0.0.1:8000/api/entity/batch_process', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({ texts })
    });
    
    const results = await response.json();
    return results;
  } catch (error) {
    console.error('批量处理失败:', error);
    throw error;
  }
}

// 提交审核结果
async function submitReview(reviewData) {
  try {
    const response = await fetch('http://127.0.0.1:8000/api/entity/review', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json'
      },
      body: JSON.stringify(reviewData)
    });
    
    const result = await response.json();
    return result;
  } catch (error) {
    console.error('提交审核失败:', error);
    throw error;
  }
}
```
