# 脚本模块 (Scripts Module)

## 模块概述

脚本模块包含各种辅助脚本，用于数据处理、分析和维护。这些脚本主要用于离线处理任务，如数据提取、迁移和分析。

## 目录结构

```
scripts/
└── extract_from_neo4j.py    # 从Neo4j提取数据的脚本
```

## 核心功能

### 1. 数据提取

- **从Neo4j提取数据**：提取Neo4j图数据库中的数据，用于数据迁移和分析
- **数据格式转换**：将提取的数据转换为适合其他系统使用的格式

## 使用方法

### 从Neo4j提取数据

```bash
# 运行提取脚本
python app/scripts/extract_from_neo4j.py
```

**功能**：从Neo4j数据库提取食谱和食材数据，保存为JSON格式。

**配置**：脚本使用 `app/config.py` 中的数据库配置。

## 常见问题

### 1. 提取失败

检查Neo4j数据库连接是否正常，以及权限是否足够。

### 2. 数据格式错误

确保Neo4j数据库中的数据格式正确，并且脚本能够正确解析。
