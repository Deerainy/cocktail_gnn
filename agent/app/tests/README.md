# 测试模块 (Tests Module)

## 模块概述

测试模块包含各种测试用例，用于验证系统的功能和性能。它确保系统的各个组件能够正常工作，并且在修改后不会破坏现有功能。

## 目录结构

```
tests/
├── __init__.py
├── test_mysql_schema.py         # MySQL schema测试
└── test_user_input_analyzer.py  # 用户输入分析器测试
```

## 核心功能

### 1. 单元测试

- **MySQL schema测试**：测试MySQL数据库的schema结构
- **用户输入分析器测试**：测试用户输入分析器的功能

### 2. 集成测试

- **功能集成测试**：测试各个组件的集成
- **端到端测试**：测试完整的系统流程

## 使用方法

### 运行测试

```bash
# 运行所有测试
python -m pytest app/tests/

# 运行特定测试
python -m pytest app/tests/test_user_input_analyzer.py
```

## 测试用例

### 1. MySQL schema测试

**功能**：验证MySQL数据库的schema结构是否正确。

**测试点**：
- 表结构是否存在
- 字段类型是否正确
- 索引是否设置

### 2. 用户输入分析器测试

**功能**：测试用户输入分析器的功能。

**测试点**：
- 实体识别是否准确
- 意图分类是否正确
- 响应生成是否合理

## 常见问题

### 1. 测试失败

检查测试环境是否正确配置，以及代码是否符合测试预期。

### 2. 测试覆盖不足

增加更多的测试用例，确保覆盖所有关键功能。
